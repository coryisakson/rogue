# Rogue

Open-source, cited, rights-aware tabletop-game knowledge platform: a continuously learning knowledge base with
setup one-pagers and cited rules chat on top. EU/GDPR-first, self-hostable, MCP-native, pluggable models and storage.

Status: Phase 0 (foundations). Design: [`docs/design/rogue-design-plan-v13.html`](docs/design/rogue-design-plan-v13.html).
Agents: [`AGENTS.md`](AGENTS.md). Progress: [`docs/PROGRESS.md`](docs/PROGRESS.md). Roadmap: [`docs/ROADMAP.md`](docs/ROADMAP.md).

```
npm install
npm run dev      # http://localhost:4321
npm run check    # typecheck + tests + build + version consistency
```
